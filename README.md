# Event Booking & QR Entry Management System

A full-stack starter for event registration, QR ticketing, and gate verification.

## Stack
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MongoDB + Mongoose

## Structure
- `client/` - attendee, organizer, and staff UI
- `server/` - API, auth, events, bookings, QR verification

## Next steps
1. Install dependencies in both workspaces.
2. Configure `.env` values for MongoDB, JWT secrets, mail, and upload storage.
3. Implement the booking flow end to end.
4. Add tests and deployment setup.

## Run
- `npm run dev:server`
- `npm run dev:client`
